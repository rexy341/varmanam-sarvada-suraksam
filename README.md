# Varmanan Sarvada Suraksam

Ideathon HACK4SDG by AIESEC, we created Varman, an disaster resilience and response coordinating system. The response coordination was handled by peer to peer mesh network resembling meshtastic but suited for disaster management with specific routing procedures, hierarchy and so on. Paired with that is Varman a PWA designed with React to work on multiple platforms as required, as a website or an app and on android, windows and apple systems. Varman has a location based prediction system with Random forest based ml model to predict probability of flooding zones based on historical data, along with a proposed statistical model also based on historical data to act as failsafe in case the ml model begins to hallucinate. The safety alert given out by CWC is analyzed, since it is not latitude or longitude based, rather village based alerts, we use our models to triage onto one decision, if cwc and either one of the models give a danger alert it is put out. If, cwc shows danger but the model shows safe, the models are kept silent. If cwc says safe but multiple areas in near vicinity are shown as danger by the both models, we give out danger. Along with that the pwa can also transmit specialized SOS signals to rescue units and the control room. The control room can organize suppliers, create pdf reports and mark safe zones for public view. Rescue units are allowed access only after verification from control room.
